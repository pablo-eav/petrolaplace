PetroLaplace™ Reservoir Core v1.0.0

Advanced Well Test Analysis & Non-Iterative Deconvolution Toolbox for MATLAB

Key Breakthrough: Eliminates Stehfest numerical divergence and Runge ringing in complex reservoir transient models (dual-porosity, shale multi-fractured horizontal wells, variable rate deconvolution) using root-free conformal Talbot integration.

Overview & Features

  • Root-Free Conformal Talbot Integration: Continuous Laplace inversion with infinitesimal complex step Bourdet derivative without finite-difference noise.
  • Non-Iterative Toeplitz-Tikhonov Deconvolution: Reconstructs constant-rate drawdown response from multi-rate erratic production history in < 2 ms.
  • High-Speed Native C99 Engine: Optional MEX acceleration compiled directly from C99 MISRA compliant code. Vectorized MATLAB fallback included.
  • Pre-built Reservoir Models: Radial storage and skin ($C_D, S$), Warren-Root dual-porosity carbonate ($\omega, \lambda$), Trilinear shale multi-fracture ($x_f, k_{SRV}$).

Quick Start

Add the toolbox to your MATLAB path:

% Run the startup script
run('start_toolbox.m');

% Or call functions directly using the namespace:
import petrolaplace.*

Example 1: Inverting Laplace Model with Bourdet Derivative

t = logspace(-2, 4, 100);
F_s = @(s) petrolaplace.model_radial_storage_skin(s, 1e3, 2.5);

% Invert Laplace and compute Bourdet derivative simultaneously
[pD, dpD] = petrolaplace.invert_laplace(F_s, t);

figure('Color','w');
loglog(t, pD, 'b-', 'LineWidth', 2); hold on;
loglog(t, dpD, 'r-', 'LineWidth', 2); grid on;
xlabel('Dimensionless Time t_D');
ylabel('Dimensionless Pressure & Derivative');
legend('p_D (Pressure)', 't_D * p_D'' (Bourdet Derivative)', 'Location', 'northwest');
title('PetroLaplace: Bourdet Storage & Skin Diagnostic Match');

Toolbox Functions

Function Description
petrolaplace.invert_laplace(F_s, t, N) Computes $f(t)$ and continuous $t \cdot f'(t)$ via conformal Talbot contour.
petrolaplace.deconvolve(t, p, q, lambda) Non-iterative Tikhonov deconvolution converting variable-rate $p(t)$ to constant-rate response.
petrolaplace.bourdet_derivative(t, p, L) Continuous Bourdet logarithmic derivative with configurable $L$-factor windowing.
petrolaplace.analyze_well(data_source, props) Automated end-to-end PTA pipeline: diagnostics, storage/skin, dual-porosity, and report.
petrolaplace.model_radial_storage_skin(s, CD, S) Laplace-space reservoir model for homogeneous radial flow with wellbore storage and skin.

SPE Field Benchmarks

The toolbox includes verified benchmark scripts replicating published Society of Petroleum Engineers (SPE) field cases:

  • examples/ex01_bourdet_storage_skin.m: Homogeneous storage and skin match vs Stehfest.
  • examples/ex02_warren_root_carbonate.m: Naturally fractured carbonate reservoir.
  • examples/ex03_shale_horizontal_mfhw.m: Multi-fractured horizontal well in tight shale ($m = 0.5$ half-slope).
  • examples/ex04_multirate_deconvolution.m: Multi-rate erratic flow deconvolution with gauge noise.

Compiling High-Speed MEX

To compile the native C99 computational engine for sub-millisecond execution:

build_mex

This compiles mex_root_free_reservoir.c and src/root_free_reservoir_core.c into mex_root_free_reservoir.mexw64 (or .mexmaca64, .mexa64).

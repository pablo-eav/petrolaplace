# PetroLaplace™ C99 High-Performance Kernel

The native computational engine (`root_free_reservoir_core.dll` and `mex_root_free_reservoir.mex`) is distributed in precompiled binary format to protect proprietary numerical inversion and deconvolution intellectual property.

- **Header:** `root_free_reservoir_core.h` contains standard C99/C++ signatures for integration.
- **Dynamic Library:** `root_free_reservoir_core.dll` (x86_64, Windows).
- **MEX Interface:** Distributed precompiled in `+petrolaplace/mex_root_free_reservoir.mex*`.

For custom enterprise source licensing, academic research partnerships, or high-performance cluster builds (Linux x86_64 / ARM64), please contact support@laplace-rootfree.org.
